旗帜训练工具 使用说明
版本：v0.5 beta1

═══════════════════════════════════════════════════════════════

一、项目概述

旗帜训练工具是一套 Minecraft 风格旗帜的创建、导入与 AI 训练系统，包含以下组件：

  旗帜训练导入器 — 旗帜图案编辑器，用于创建和编辑旗帜
  旗帜训练器     — AI 训练引擎，基于 ViT 架构进行旗帜学习
  旗帜识别器     — 旗帜图片逆向识别工具（BannerDyeOrderReverser）

训练器和导入器联动运行：关闭任一窗口，另一个自动关闭。

注意：本版本为 v0.5 beta1，功能仍在持续完善中，如遇问题请反馈。

二、启动方式

  方式一：双击 trainer.pyw
    → 选择训练模式 → 加载界面 → 训练器（左半屏）+ 导入器（右半屏）

  方式二：双击 importer.pyw
    → 选择训练模式 → 加载界面 → 训练器（左半屏）+ 导入器（右半屏）

  方式三：双击 BannerDyeOrderReverser/bdor.pyw
    → 独立运行旗帜识别器

  方式四：双击 .mbtl 文件
    → 需训练工具已启动，导入器自动加载文件内容
    → 若训练工具未启动，弹窗提示先启动
    → 若文件格式无效，弹窗报错
    → 若导入器已有数据，弹出合并/替换选择

注意：使用 .pyw 扩展名运行，不会出现命令提示符窗口。
      调试模式勾选后会显示命令提示符用于查看日志。

三、旗帜训练导入器

3.1 编辑旗帜

  编辑区位于左侧，包含：
    背景颜色选择 — 16 种标准颜色（索引 0~15）
    图案添加     — 选择图案类型和颜色后点击添加
    图案层管理   — 选中已添加的图案可上移/下移/删除

  限制说明：
    - 每面旗帜最多 16 层图案
    - 背景颜色：0~15（16 种标准颜色）
    - 图案颜色：0~15
    - 图案类型：0~43（44 种标准图案）

3.2 保存与导出

  保存旗帜 — 编辑完成后点击"保存"，旗帜加入右侧序列列表
  导出到训练器 — 数据自动传输至旗帜训练器
  导出序列文件 — 将序列保存为 .mbtl 文件

3.3 批量生成

  随机生成区域包含两个标签页：

  普通生成标签页：
    - 设置生成数量、颜色数范围、图案数范围
    - 支持去重底色和去重复旗选项
    - 点击"生成随机旗帜"批量生成

  纠偏生成标签页：
    - 颜色纠偏模式：基于已有旗帜，通过控制变量法生成对比数据
      · 变化背景色（默认开启）：遍历 16 种背景色，图案类型和颜色不变
      · 变化图案颜色（默认关闭）：随机变化图案颜色，背景色和图案类型不变
      · 可同时开启两项，生成更多组合
    - 图案纠偏模式：基于已有旗帜，随机替换图案类型，颜色不变
      · 图案类型范围：可指定最小和最大图案索引（1~42）
      · 用于训练模型区分相似图案类型
    - 每组重复：每面源旗帜生成几组变体
    - 杜绝重复旗帜：跳过与已有旗帜完全相同的生成结果

3.4 导入 .mbtl 文件

  通过"导入旗帜文件"按钮或双击 .mbtl 文件均可导入。
  导入时若导入器已有数据，弹出选择：
    - 合并：新数据追加到现有序列末尾
    - 替换：清除现有数据，替换为新数据

四、旗帜训练器

4.1 导入旗帜文件

  点击"导入旗帜文件"按钮，选择 .mbtl 格式的旗帜数据文件。
  导入后旗帜显示在预览区（8 个/页，支持翻页）。
  训练进行中禁止导入新数据，需先停止训练。

4.2 训练参数

  训练轮数：1~100（默认 10）
  批次大小：1~32（默认 8）
  学习率：0.001 / 0.0001 / 0.00001（默认 0.0001）

4.3 两阶段训练

  训练自动分两阶段进行：
    冻结阶段（前 1/3 轮）— 冻结 ViT backbone，只训练分类头
    微调阶段（后 2/3 轮）— 解冻 ViT 最后 4 层，降低学习率微调

  进度显示：
    [冻结] Epoch 1/10 — 正在训练分类头
    [微调] Epoch 4/10 — 正在微调整个模型

4.4 逐个旗帜训练

  训练过程中，每个旗帜逐个完成训练：
    - 已完成训练的旗帜显示灰色 + ✓ 标记
    - 正在训练的旗帜显示进度条
    - 进度条只增不减，不会回弹

4.5 模型保存与加载

  模型保存路径：models/model_file/banner_vit_model.pth
  点击"保存模型"可手动保存当前模型权重。
  点击"继续训练"可加载已有模型继续训练。

4.6 Loss 趋势图

  训练完成后，"查看Loss"按钮变为可用，点击可查看训练 Loss 变化趋势。
  图表优先使用 matplotlib 渲染，若未安装则自动使用内置 Qt 图表。

4.7 翻页浏览

  每页显示 8 个旗帜（2 行 × 4 列），支持翻页。

五、旗帜识别器（BannerDyeOrderReverser）

  独立运行，用于从旗帜图片识别出旗帜数据。

  使用方法：
    1. 加载模型（点击"加载默认模型"或"选择模型文件"）
    2. 导入旗帜图片（从文件或剪贴板）
    3. 点击"识别旗帜"
    4. 查看识别结果：序列信息 + 还原预览图

  识别结果包含：
    - 序列信息（MC 旗帜命令格式）
    - 原始数据数组
    - 背景颜色和图案详情
    - 还原后的旗帜预览图

六、窗口联动

七、数据格式

  MBTL（Minecraft Banner Training Layout）是专用的二进制旗帜序列文件格式。

  文件结构：
    ┌──────────┬──────────┬──────────┬──────────────────┐
    │ 魔数(4B) │ 版本(2B) │ 数量(4B) │ 旗帜数据(变长)    │
    │  MBTL    │  0x0001  │  N       │  ...             │
    └──────────┴──────────┴──────────┴──────────────────┘

  魔数：4字节 ASCII "MBTL"（0x4D42544C），用于快速识别文件类型
  版本号：2字节小端序 uint16，当前版本 = 1
  旗帜数量：4字节小端序 uint32
  每面旗帜：
    - 背景色：1字节 uint8（0~15）
    - 图案层数：1字节 uint8（0~16）
    - 每层图案：图案类型 1字节 + 图案颜色 1字节

  索引范围：
    背景色/颜色索引：0~15
    图案类型索引：0~43

八、常见问题

  Q: 训练后颜色识别不准？
  A: 确保训练数据量充足（每种颜色至少 20 个样本），
     增加训练轮数（建议 20+），使用两阶段训练会自动优化。
     使用纠偏生成的颜色纠偏模式，针对性补充混淆颜色对。
     详细纠偏方法请参考"训练流程说明.txt"。

  Q: 训练进行中无法导入新数据？
  A: 这是防破坏机制，请先停止训练再导入。

  Q: 旗帜识别器找不到模型？
  A: 先在训练器中训练并保存模型，默认保存到 models/model_file/ 目录。

  Q: 双击 .mbtl 文件提示"请先启动旗帜训练工具"？
  A: 需要先通过方式一或方式二启动训练工具，再双击 .mbtl 文件。
     导入器启动后会自动检测并加载文件。

  Q: 图案加载失败？
  A: 确保 images/base and patterns/ 目录下有完整的图案文件。

  Q: Loss 图表无法显示？
  A: 安装 matplotlib（pip install matplotlib）可获得更精美的图表，
     未安装时会自动使用内置 Qt 图表作为替代。
