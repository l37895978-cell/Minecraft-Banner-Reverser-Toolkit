# Minecraft-Banner-Reverser-Toolkit
使用 Vibe Coding 方式编写基于 ViT/D-ViT 技术的 Minecraft 旗帜图案逆向识别工具包，含训练器 / 识别器 / 导入器三件套。Develop a Minecraft banner pattern reverse recognition toolkit based on ViT/D-ViT technologies using the Vibe Coding approach, consisting of three integrated components: a trainer, a recognizer, and an importer.
